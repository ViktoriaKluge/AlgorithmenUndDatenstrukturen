# Algorithmen und Datenstrukturen

Drei Programmieraufgaben aus der Lehrveranstaltung *Algorithmen und Datenstrukturen* (Bachelor Informatik, 2. Semester), umgesetzt in C++17 im Zweierteam.

Die Aufgaben gaben jeweils nur vor, was das Programm können muss. Die Wahl der Datenstrukturen und Algorithmen und deren Begründung lag bei uns. Jedes Projekt hat eine eigene README mit Aufgabe, Umsetzung, Begründung und Laufzeitanalyse.

| # | Projekt | Thema | Kern |
|---|---------|-------|------|
| 1 | [Aktienverwaltung](01-aktien-hashtable/) | Hashing | Eigene Hashtabelle mit quadratischer Sondierung, Suche nach Name oder Kürzel |
| 2 | [Treecheck](02-avl-baum/) | Bäume | Binärer Suchbaum aus Datei, AVL-Prüfung, Suche und Subtree-Erkennung |
| 3 | [Kürzester Weg im Öffi-Netz](03-graph-kuerzester-weg/) | Graphen | Dijkstra-Variante auf dem Wiener U-Bahn-/Straßenbahnnetz inkl. Umstiegen |

Alle Projekte sind ohne externe Abhängigkeiten.
